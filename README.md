# Class Score · สังคมศึกษา 5

เว็บตรวจสอบคะแนนจากรหัสนักเรียน 5 หลัก โทนเขียว เหลือง และขาว รองรับมือถือ มีช่วงโหลดประมาณ 2 วินาทีและข้อความให้กำลังใจตามคะแนน รวมถึงข้อความเฉพาะสำหรับผู้ขาดสอบ

## ข้อมูล

นำเข้าจาก `ฐานข้อมูล.xlsx` แผ่นงานแรก 280 รายการ คอลัมน์ A–I: รหัสนักเรียน คำนำหน้า ชื่อ สกุล ก่อนกลางภาค หลังกลางภาค สอบปลายภาค รวม เกรด

- แสดงคะแนนรวมและเกรดจากไฟล์โดยตรง ไม่คำนวณเกรดใหม่
- รักษาค่า `ขาดสอบ` และเลข 0 ตามต้นฉบับ ไม่แปลงเป็นค่าว่าง
- ไม่ระบุคะแนนเต็มแต่ละส่วน เพราะไฟล์ไม่ได้กำหนดไว้
- ข้อความให้กำลังใจใช้ช่วงคะแนนรวม ≥80, ≥70, ≥50 และ <50 เป็นการเลือกข้อความเท่านั้น ไม่ใช่เกณฑ์คำนวณเกรด ผู้ขาดสอบจะได้ข้อความเฉพาะ

## เริ่มใช้งานในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจสำหรับหน้าเว็บ

1. สร้าง `.env` โดยกำหนด `SCORE_DATA_KEY` เป็นกุญแจของชุดข้อมูล (64 ตัวอักษร hexadecimal)
2. `npm run dev`
3. เปิด `http://localhost:4173`
4. ตรวจสอบระบบด้วย `npm test` และ `npm run build`

## อัปเดตคะแนน

ติดตั้ง Python และ openpyxl แล้วเรียก `npm run import -- "/path/to/ฐานข้อมูล.xlsx"` ในเครื่องที่มี `.env` เดิม หากต้องเลือก Python ให้ใช้ตัวแปร `PYTHON_BIN`

สคริปต์ตรวจหัวคอลัมน์ รหัสซ้ำ คะแนนรวม และข้อมูลที่ขาด แล้วเข้ารหัส AES-256-GCM ไปที่ `data/scores.enc.json` โดยไม่เขียนข้อมูลนักเรียนแบบอ่านได้ลงดิสก์ กุญแจจะสร้างใน `.env` เมื่อยังไม่มีเท่านั้น เก็บกุญแจเดิมเมื่ออัปเดตข้อมูล แล้วนำไฟล์เข้ารหัสชุดใหม่ขึ้น Netlify อีกครั้ง

## Netlify

- Publish directory: `public`
- Build command: `npm run build`
- Functions directory: `netlify/functions`
- กำหนด `SCORE_DATA_KEY` ใน Environment variables ให้ครอบคลุม Functions และ production context ก่อน deploy
- Custom domain: `classscore.grits.online`
- หากใช้ DNS ภายนอก ให้ตั้ง CNAME ชื่อ `classscore` ไปยังชื่อไซต์ `.netlify.app` จริง หากโดเมนใช้ Netlify DNS ให้เพิ่ม custom domain บนไซต์และตรวจสอบ record ที่ Netlify สร้าง
- [เอกสาร DNS ของ Netlify](https://docs.netlify.com/manage/domains/configure-domains/configure-external-dns/)

## การดูแลข้อมูล

repo นี้เก็บเฉพาะข้อมูลเข้ารหัส กุญแจและไฟล์ Excel ถูกกันออกจาก Git หน้าเว็บไม่ดาวน์โหลดรายชื่อทั้งชั้น API ส่งกลับเพียงรายการเดียวผ่าน POST และใช้ `no-store` มี Netlify rate limiting 30 ครั้งต่อนาทีต่อ IP/โดเมน (เครื่องนักเรียนที่ใช้เครือข่ายเดียวกันอาจใช้โควตาร่วมกัน) ไม่มี analytics และไม่เก็บคะแนนใน localStorage

**รหัสนักเรียนเป็นตัวค้นหา ไม่ใช่การยืนยันตัวตน:** ผู้ที่รู้รหัสของผู้อื่นยังค้นดูผลได้ หากต้องการยืนยันเจ้าของคะแนน ควรเพิ่ม PIN ส่วนตัวหรือบัญชีนักเรียนภายหลัง ระบบนี้ทำตามการค้นหาด้วยรหัสอย่างเดียวที่กำหนดไว้
